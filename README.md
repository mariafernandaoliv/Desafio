Nome do projeto: Bolinho de Papel 

Sobre: uma empresa fictícia de papelaria personalizada para festas infantis.

Tecnologias:

HTML5; CSS3; Git; GitHub e GitHub Pages.

A página utiliza uma paleta colorida, relacionada ao universo das festas infantis. A fonte Bairro foi aplicada nos títulos e a McLaren nos demais textos.

Inteligência Artificial:
A Inteligência Artificial foi utilizada como apoio para: planejar a estrutura semântica do HTML; organizar e explicar o CSS; criar sugestões de textos; corrigir problemas de alinhamento.
